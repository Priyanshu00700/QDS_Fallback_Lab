Users and roles

    What each role does
    Sender
    Signs the message and sends it.
    Receiver
    Checks the signature before accepting the message.
    Validator
    A second, independent checker. Without one, an attacker on the receiver's quantum link can fool the receiver.
    Attacker
    Interferes with the main route, the backup route or the entanglement link. Set the attack on the user.
    Bystander
    Sits in the network and does nothing.
